# PhoneCam LAN

Android → домашний Wi-Fi → OBS на Windows 11 → виртуальная камера → Discord / Zoom.

Нативное Android-приложение, без сайта на телефоне, без аккаунта и облачной передачи видео. GitHub только хранит код и собирает APK. Публичная версия 0.3.0 для **Android 10–17**: выбор передней и задней камеры, размер ближайший к 640×480, до 10 кадров/с, без микрофона. Передняя камера выбрана по умолчанию; приложение запоминает выбор. Это версия для публичного тестирования. На конкретном телефоне необходимо проверить камеры и работу при блокировке экрана. [Приватность](PRIVACY.md).

## Получить APK без Android Studio

1. Открыть ссылку скачивания выше или [Releases](https://github.com/myhmanmyhman23-tech/phonecam-lan/releases) → последний выпуск.
2. В **Assets** скачать `PhoneCam-LAN.apk` и установить на Android 10 или новее. Вход в GitHub не требуется. Это APK вне Google Play: разрешить установку для используемого браузера / файлового менеджера, если Android спросит.
3. Разрешить камеру и уведомления. На Android 17 разрешить доступ к локальной сети / ближайшим устройствам.
4. Телефон и ПК подключить к одному роутеру. ПК может быть подключён кабелем Ethernet. Гостевая сеть / изоляция клиентов мешают соединению.
5. Открыть приложение, выбрать **Передняя** или **Задняя**, нажать **Начать трансляцию**, дождаться статуса работающей камеры. Скопировать показанную ссылку на ПК. Теперь можно проверить блокировку экрана.

Для смены камеры нажать **Остановить**, выбрать другую и снова нажать **Начать трансляцию**. Выбор камеры недоступен во время передачи. Ссылка остаётся прежней, в OBS менять её не требуется. Передаётся одна выбранная камера за раз. Если OBS не возобновляет изображение после перезапуска, скрыть и снова показать медиаисточник или переоткрыть его свойства. Если обновление APK требует удаления старой версии, после переустановки скопировать новую ссылку в OBS.

## OBS и Discord / Zoom

Нужен установленный [OBS Studio](https://obsproject.com/). Компиляторы, Android Studio, VLC и отдельные плагины не нужны.

1. В OBS добавить источник **Медиаисточник / Media Source**.
2. Снять **Локальный файл / Local File**.
3. В поле **Ввод / Input** вставить целиком ссылку из приложения: `http://IP-ТЕЛЕФОНА:8080/stream?token=...`.
4. В **Формат ввода / Input Format** указать `mpjpeg`. Отключить аппаратное декодирование. Буфер сети поставить 1 МБ для начала; если видео зависает, проверить Wi-Fi.
5. Вписать источник в холст (**Ctrl+F**); изображение повернуто под портретный режим телефона. При необходимости повернуть источник в OBS на 90° и снова вписать.
6. Нажать **Запустить виртуальную камеру / Start Virtual Camera**.
7. В Discord / Zoom выбрать **OBS Virtual Camera**. Звук выбрать от микрофона ПК.

Документация OBS: [медиаисточники](https://obsproject.com/kb/media-sources), [виртуальная камера](https://obsproject.com/kb/virtual-camera-guide).

## Блокировка экрана и Redmi

Служба камеры запускается **вручную из открытого приложения**, затем продолжает захват с постоянным уведомлением и частичной блокировкой сна процессора. Экран не удерживается включённым. Сеанс ограничен четырьмя часами, затем требуется ручной перезапуск. Нажать **Остановить** в приложении / уведомлении, чтобы закрыть камеру и сетевые соединения.

На MIUI настройки питания могут остановить трансляцию: для PhoneCam LAN выбрать батарею **Без ограничений** (название зависит от версии). Не обещаем одинаковую работу всех прошивок. При ошибке / отзыве разрешения / перезагрузке приложение не запускает камеру автоматически: разблокировать телефон и запустить трансляцию снова. [Правила Android для службы камеры](https://developer.android.com/develop/background-work/services/fgs/service-types).

## Защита и ограничения

- Случайный токен 192 бит создаётся на телефоне. Без полной ссылки сервер не отдаёт кадры. Токен хранится локально; ссылка не отправляется в GitHub.
- Сервер слушает только IPv4-адрес Wi-Fi, не мобильный интерфейс. Максимум четыре клиента. Нет записи, удалённого запуска, автозапуска или доступа к файлам.
- HTTP передаёт видео и токен без шифрования. Использовать только в доверенной домашней сети. Не пробрасывать порт 8080 в интернет. Доступ из разных сетей в эту версию не входит.
- Wi-Fi IP может измениться: переписать ссылку в OBS. Смена сети требует остановить и заново начать трансляцию.
- MJPEG использует больше трафика и батареи, чем H.264. Телефон может нагреваться. 10 кадров/с — ограничение прототипа, не полноценные 30/60 fps.
- Публичные APK подписаны постоянным ключом, который хранится в GitHub Secrets, а не в исходниках. Обновления публичных выпусков устанавливаются поверх этой версии. При переходе со старых debug APK 0.1/0.2 удалить старую версию и установить публичную; ссылка после переустановки изменится, её нужно заново вставить в OBS.
- Минимальная версия Android 10 (API 29), compile/target Android 17 (API 37). Установочного ограничения сверху нет; будущие Android и beta / Canary отдельно не проверены. Совместимость по SDK не является подтверждением работы всех камер и прошивок.

## Проверка на реальном телефоне

Проверить: изображение в OBS → OBS Virtual Camera в Discord → заблокировать экран на 10 минут → проверить непрерывность видео → остановить из уведомления → убедиться, что поток закрыт. Затем проверить отзыв разрешения камеры и повторный ручной запуск. CI проверяет сборку, lint, авторизацию HTTP, multipart-кадры, отключение клиентов и чтение потока FFmpeg; он не заменяет проверку камеры и MIUI на телефоне.

## Для разработчика

Java 17, Gradle 9.3.1, Android SDK 37, AGP 9.1.1. Для локальной проверки: `gradle assembleDebug lintDebug`. GitHub Actions выполняет `assembleRelease lintRelease`, проверяет подпись и SDK-манифест, публикует APK и SHA256SUMS. Ключ и пароль передаются через GitHub Secrets. Без сторонних зависимостей приложения.
