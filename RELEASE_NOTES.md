Публичная версия PhoneCam LAN 0.3.0 для Android 10–17.

- Скачать и установить `PhoneCam-LAN.apk`. `SHA256SUMS` содержит контрольную сумму.
- Передняя и задняя камера, передняя выбрана по умолчанию. Для смены: остановить → выбрать камеру → начать.
- Android 17: приложение запрашивает разрешение на локальную сеть. Разрешить его для подключения ПК.
- Современный интерфейс учитывает системные панели Android 15–17.
- Постоянная подпись: следующие публичные обновления устанавливаются поверх этой версии, пока сохранён тот же ключ подписи и applicationId.
- При переходе со старого debug APK 0.1/0.2 нужно удалить старую версию, установить новую и скопировать новую ссылку в OBS.

Телефон и ПК должны быть в одной доверенной сети. На ПК пока нужен OBS: Медиаисточник → отключить «Локальный файл» → ссылка из приложения → формат `mpjpeg` → запустить виртуальную камеру. В Discord / Zoom выбрать OBS Virtual Camera.

Это публичная версия для тестирования. Минимум Android 10, сборка и target SDK Android 17. Поддержка по SDK не означает проверку камеры на каждом телефоне или каждой версии Android. MIUI и другие прошивки могут ограничивать камеру при блокировке экрана. Новые beta / Canary Android не заявлены как проверенные.

Видео и ссылка не отправляются в облако. HTTP не шифрует поток: использовать доверенный домашний Wi-Fi, не публиковать ссылку и не открывать порт 8080 в интернет.
