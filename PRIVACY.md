# Приватность PhoneCam LAN

Приложение не использует аккаунты, рекламу, аналитику или сервер разработчика. Оно не записывает видео, не запрашивает микрофон, контакты, местоположение или доступ к файлам.

Камера включается после нажатия «Начать трансляцию» и предоставления разрешения. Видео отдаётся клиентам, знающим полную ссылку с токеном, через Wi-Fi-интерфейс телефона. Для остановки нажать «Остановить» в приложении или уведомлении. После перезагрузки камеры не включаются автоматически.

Токен подключения и выбор камеры сохраняются в приватных настройках приложения. Они удаляются при удалении приложения. GitHub получает исходники и выполняет сборку; приложение не передаёт туда видео или ссылку подключения.

Разрешения: камера для захвата, сеть для передачи, состояние сети для поиска Wi-Fi-адреса, локальная сеть на Android 17+ для общения с ПК, служба камеры и уведомление для работы при выключенном экране, частичная блокировка сна процессора для непрерывной передачи.

HTTP не обеспечивает шифрование. Используйте только доверенную домашнюю сеть. Полная ссылка даёт доступ к видео; не публикуйте её и не открывайте порт приложения в интернет. OBS и Discord / Zoom обрабатывают полученное видео по собственным настройкам и политикам.
